# Aussie Trainer

Приложение для индивидуальной дрессировки австралийской овчарки: 12-недельный курс, тренировки на прогулке с учётом каждой попытки, адаптация сложности, прогресс, дневник поведения и отчёт для ChatGPT или Claude.

**Открыть:** https://282yzkvc49-svg.github.io/dog-trener/ — в Safari на iPhone: «Поделиться» → «На экран „Домой“». Данные вводите уже в приложении с иконки.

## Общая собака: тренировать вдвоём

Собаку можно вести на двух телефонах — что отметит один, через несколько секунд появится у другого. Облако — тот же проект Supabase, что у приложения «Бережно», подходит тот же аккаунт.

1. Один раз: Supabase → SQL Editor → вставить [`app/supabase/aussie_trainer.sql`](app/supabase/aussie_trainer.sql) → Run.
2. Первый телефон: «Настройки» → «Общая собака» → войти → «Сделать собаку общей» → «Отправить приглашение».
3. Второй телефон: установить приложение → «Присоединиться к общей собаке» → войти → ввести код.

## Что где лежит

- Корень репозитория — готовый сайт для GitHub Pages: `index.html`, `sw.js`, `manifest.webmanifest`, иконки. Эти файлы собираются автоматически, вручную их не правят.
- `app/` — исходный код (React + TypeScript + Tailwind), SQL для облака (`app/supabase/`), тесты и подробный [README](app/README.md): установка, запуск, сборка, архитектура, результаты тестов, ограничения.

## Обновление сайта

```bash
cd app
npm install
npm run publish:root   # сборка и копирование готовых файлов в корень репозитория
```

После коммита GitHub Pages обновится за 1–2 минуты, а приложение на телефоне предложит «Обновить». Данные тренировок при обновлении сохраняются.
