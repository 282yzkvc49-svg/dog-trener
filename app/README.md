# Aussie Trainer

PWA для индивидуальной дрессировки австралийской овчарки: 12-недельный курс, пошаговые тренировки на прогулке с учётом каждой попытки, адаптация сложности, аналитика, дневник поведения и отчёт для ChatGPT или Claude. Полностью на русском, работает без интернета, все данные хранятся на устройстве.

## Быстрый старт

Нужен Node.js 20+.

```bash
npm install          # зависимости
npm run dev          # сборка + автопересборка + сервер http://localhost:5173
npm run build        # production-сборка в dist/
npm run preview      # раздать dist/ на http://localhost:4173
npm test             # модульные тесты (node:test через tsx)
npm run typecheck    # проверка типов TypeScript
npx playwright install chromium   # один раз, для сценарных тестов
npm run test:e2e     # сборка + сценарии Playwright
```

Если Chrome уже установлен, можно не скачивать браузер: `CHROME_PATH=/путь/к/chrome npm run test:e2e`.

Иконки пересоздаются из `scripts/icon.svg`: `npm run icons` (нужен Python 3 с Pillow и `rsvg-convert` или `cairosvg`).

## Публикация (бесплатный HTTPS)

Рекомендуется **GitHub Pages**. Сборка плоская — все файлы в корне `dist/`, без подпапок, поэтому их можно загрузить даже с iPhone или iPad через браузер:

1. github.com → «+» → New repository, например `aussie-trainer`, видимость **Public**.
2. Add file → Upload files → выбрать **все файлы** из `dist/` (`index.html`, `sw.js`, `manifest.webmanifest`, пять PNG) → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → `main`, `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://<имя>.github.io/aussie-trainer/`.

Подойдут и Netlify, и Cloudflare Pages: любой статический хостинг с HTTPS. Все пути относительные, маршруты на `#/…`, настройка сервера не нужна.

**В этом репозитории** (`dog-trener`) готовый сайт лежит в корне, а исходники — в `app/`. Команда `npm run publish:root` собирает и копирует файлы в корень.

**Обновление:** загрузить поверх изменившиеся файлы (обычно `index.html` и `sw.js`). При следующем открытии приложение покажет «Доступна новая версия» → «Обновить». Данные в IndexedDB при этом не трогаются.

## Установка на iPhone

1. Открыть адрес сайта **в Safari**.
2. «Поделиться» → «На экран „Домой“» → «Добавить».
3. Запускать с иконки и только потом вводить данные: у установленного приложения своё хранилище, данные из вкладки Safari туда не переходят.
4. Перенос на новый телефон: «Настройки» → «Сохранить резервную копию» → файл в «Файлы» → на новом устройстве на первом экране «Восстановить из резервной копии».

## Архитектура

```
src/
  main.tsx, App.tsx       вход, маршруты на hash (#/today), нижняя навигация
  content/                данные курса: 21 упражнение с уровнями, 12-недельная программа
  domain/                 чистая логика без DOM — покрыта модульными тестами
    types.ts              модель данных
    plan.ts               справочник упражнений, описание пунктов, оценка длительности
    schedule.ts           создание курса, статусы дней, пауза, перенос, смена старта
    adaptation.ts         правила 70/80%, две сессии в сопоставимой обстановке, стресс
    training.ts           наблюдения, пересчёт попыток, подсказки безопасности
    metrics.ts            выполнение плана, доля успеха, уровни, успех по обстановке
    report.ts             недельный отчёт и текст для ИИ, JSON
    exporters.ts          ICS (календарь) и CSV
    backup.ts             формат резервной копии, проверка, миграции формата
  db/
    idb.ts                IndexedDB: версии схемы, атомарные пакеты, уведомления
    store.ts              состояние приложения в памяти, перезагрузка после записи
    repo.ts               операции: тренировка, попытки, уровни, дневник, фото, копии
  screens/                экраны
  ui/                     дизайн-система: кнопки, листы, графики, диалоги
  sw.js                   service worker: офлайн-кеш, обновление по кнопке
scripts/build.mjs         сборка: esbuild + Tailwind v4 → один index.html
tests/unit, tests/e2e     модульные тесты и сценарии Playwright
```

**Данные.** IndexedDB `aussie-trainer`, схема версии 1: `settings, dogs, programs, days, sessions, trainings, results, attempts, levels, levelChanges, journal, photos, customExercises, reports`. Каждая попытка — отдельная запись `attempts`, счётчики результата пересчитываются из попыток. Встроенные упражнения живут в коде (обновляются с приложением), свои — в `customExercises`. При изменении схемы увеличивается `DB_VERSION` и добавляется шаг в `upgrade()`; у резервной копии своя версия формата и `migrateBackup()`.

**Четыре показателя не смешиваются:** выполнение плана (adherence), доля правильных попыток, текущий уровень навыка, успех по обстановке (дом / тихое место / умеренные / сильные отвлечения). Пропуски и «не было встреч» не считаются неудачами; при сильном возбуждении удачные попытки не засчитываются.

**Стек.** React 19 + TypeScript, Tailwind CSS v4, иконки Lucide (`react-icons/lu`). По ТЗ предпочтительны Vite, Dexie, Recharts, vite-plugin-pwa и Vitest; в среде сборки не было доступа к npm, поэтому использованы эквиваленты без внешних зависимостей: esbuild, свой слой IndexedDB с миграциями, свои SVG-графики, свой service worker, `node:test`. Пользовательские возможности те же; развёртывание проще — сайт из 8 файлов. Файл `typings/react.d.ts` — компактные типы React вместо `@types/react`; если поставить `@types/react`, его нужно удалить.

## Проверено

- `npm test` — 46 модульных тестов: шаблон курса (84 дня, недели 1–2 по ТЗ, все три направления каждый день недель 3–12), расписание, пауза, перенос, смена старта, правила адаптации, метрики, отчёт, резервная копия, ICS, CSV.
- `npm run test:e2e` — 15 сценариев в Chromium с размером iPhone 13: первый запуск, профиль, завершение упражнения, прерывание и восстановление после перезагрузки, пропуск, день отдыха, перенос, смена даты старта, переход между неделями, адаптация сложности, отчёт для ИИ и копирование, экспорт → удаление → импорт, офлайн, обновление service worker без потери данных, отсутствие горизонтальной прокрутки на 320/390/820/1280 px, наблюдения с подсказкой безопасности, дневник.

## Известные ограничения

- Данные живут только в браузере устройства. iOS может удалить их при нехватке места или очистке данных Safari — регулярно сохраняйте резервную копию.
- Напоминания работают внутри приложения; фоновых push-уведомлений нет. Для надёжных напоминаний — выгрузка расписания в календарь (.ics). Web Push — будущая функция (нужны сервер и согласие).
- Сценарные тесты выполнялись в Chromium; поведение Safari (установка, системное меню «Поделиться», Dynamic Type) нужно проверить на iPhone.
- Седьмой день каждой недели курса — отдых; при старте не с понедельника отдых выпадает на другой день недели. Настройка «Дни занятий» влияет на напоминания и календарь, а не на раскладку курса.
- Интерфейс рассчитан на одну собаку (модель данных допускает несколько).
- Длительность занятий — оценка по числу повторов.
- Фото в дневнике: до 4 на запись, уменьшаются до 1280 px.
